## 原生 IP、双 ISP、9929、CN2 GIA 各管什么

这四个词经常被混着讲，其实分属两个维度。

**IP 属性管“平台怎么判断你”。** 原生 IP 指 IP 段的注册归属与机房所在地一致，在 MaxMind 这类库里查出来是美国本地 ISP，而非转租或广播过来的地址段。双 ISP 更进一步：ASN 和 Company 字段被识别成 ISP 类型，而非 hosting 或 datacenter，在平台眼里更接近一条家庭宽带。TikTok 这类按 IP 做风控的平台，对机房段的容忍度明显更低，这就是做账号的人愿意为“家宽属性”多付钱的原因。WePC 的美国线全档都是这个属性，不是只有贵的那档才有。

**线路管“数据怎么回国”。** 9929 和 4837 都是联通的骨干线路，9929 优先级更高、绕路更少，晚高峰表现更稳；4837 便宜，能应付日常。CN2 GIA 是电信的精品网，WePC 美国线没有这个选项，别拿它当对比基准。

**自己验一遍再决定。** 拿到机器后先跑 whois 和 ipinfo，看 ASN 与 Company 写的是 ISP 还是 hosting。不同数据库口径不一致，ip2location 对家宽段的判断通常比 ipinfo 保守，只看一家容易得出相反结论。第三方测评对 WePC 洛杉矶线的记录是：原生美国 IPv4 归属洛杉矶，多个库识别为家宽属性，去程三网直连圣何塞后接 Cogent 进机房，回程三网强制走 AS9929 回国。

**IP 属性不保证解锁。** 平台的风控名单是动态的，同一段 IP 上个月能过、这个月可能就被标记。原生 IP 或家宽 IP 降低的是被识别为机房的概率，不是拿到免死金牌。任何声称“保证解锁某平台”的商家说法都不必信。

## 常见问题

**原生 IP 和双 ISP 家宽 IP 差在哪？**

原生 IP 说的是归属地真实，IP 段确实注册在当地的 ISP 名下。双 ISP 说的是 ASN 属性，检测工具会把这条 IP 认成住宅宽带用户而非机房。前者解决“你是哪国人”，后者解决“你像不像真实家庭用户”。做账号运营，后者更关键。

**AUD$12.90 和 AUD$15.90 到底差在哪，值不值？**

只差回程线路。前者走 4837，后者走 9929，配置、带宽、流量完全一样。不直播、不跑实时性要求高的业务，这 3 澳元省下来；天天开播，加钱换稳定。

**1.5TB 流量够跑直播吗？**

按双向计，够一个主播每天播三四个小时，具体取决于码率。多主播共用一台，或者同时跑下载和上传，很容易月中就见底，之后被限到 3Mbps。这种情况直接看高配定制机，或者按流量包另算。

**能保证解锁 TikTok 或 Netflix 吗？**

不能。商家给的是家宽属性的美国 IP，能显著降低被识别为机房的概率，但平台名单随时在变。买之前用最低档月付试一周，是成本最低的验证方式。

**年付划算还是月付划算？**

按 8 折和 9 折的差价，年付一年省 10% 左右，前提是这台机器你会用满一年。第一次买建议月付，跑一周确认线路和解锁都符合预期再转年付，别为了省 10% 把自己锁在一台不合适的机器上。
